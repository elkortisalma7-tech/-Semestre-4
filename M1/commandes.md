# Installation PHP et préparation de l'environnement local

## 1. Vérifier la version de PHP

```bash
php -v
```

## 2. Démarrer le serveur local

```bash
php -S localhost:8000
```

## 3. Tester dans le navigateur

http://localhost:8000/test-serveur.php

## 4. Arrêter le serveur

```bash
Ctrl + C
```

## Résultat

Le message "Environnement local PHP opérationnel" s'affiche correctement dans le navigateur.
